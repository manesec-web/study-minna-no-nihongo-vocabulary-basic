# 大家の單詞

背單詞的小網站，做法參考《大家の動詞轉型練習》。打開網頁就能用，不用註冊、不用安裝、不用付費。站名是 **大家の單詞**。

單詞在 `vol/lesson_1.json` 到 `vol/lesson_50.json`，共 1,747 詞、每詞 20 句。欄位說明在 [`docs/data-contract.md`](docs/data-contract.md)。這些檔案不要改。

首頁大標是 **大家の日本語**，副標是 **單詞練習**，下面一行 **涵蓋初級 1 – 50 課的單詞**；網頁標題（分頁名稱）仍是 **大家の單詞**。

## 三個入口

首頁有三個按鈕，對應動詞站的三種練習，不是「學習」：

- **單詞** — 像字典：一次看一個詞。有漢字就標讀音，另外有中文、詞性、例句（每次隨機顯示 5 句）和字形對照，可以左右換詞。
- **練習** — 像翻卡：正面出題，點一下翻面。預設看日文、答中文。
- **測驗** — 按鈕在主頁上。點進去是空白頁，只有返回和標題「測驗」。

字形對照的每一列都可以點開：會進入一張「字形對照」細節頁，列出簡、繁、日三種寫法，並可用「播放筆順」看筆順動畫。

## 跟動詞站不一樣的地方

| | 動詞轉型練習 | 這個站 |
|---|---|---|
| 參考程式 | `/project/game-japanese-katsuyou-basic` | 本倉庫 |
| 主頁按鈕 | 學習、字典、翻卡練習、測驗 | **單詞、練習、測驗** |
| 學習／變形說明 | 有 | **沒有** |
| 品牌色 | 靛紫，頁面漸層接到琥珀色 | **藍色**（淺色、深色都是藍） |
| 站名 | 大家の動詞轉型練習 | **大家の單詞** |
| 字典內容 | `vol/` 裡 386 個動詞、15 種變形 | **`vol/` 裡 50 課、1,747 個單詞** |
| 測驗 | 假名鍵盤，答完一題才下一題 | **空白頁**。按鈕在，題目以後再做 |
| Google Tag | 有容器與評估 ID | **先留空**。ID 等使用者提供後再填 |

## 怎麼用

1. 打開網址，等單詞載入完（第一次要下載資料，之後就快了）。
2. 首頁選「單詞」逐個看，或選「練習」翻卡。
3. 練習時選要練的課次；翻卡還可以選方向（看日文答中文／看中文答日文）。
4. 按「開始」。單詞與翻卡的設定會記在自己的裝置裡，下次打開不用重選。
5. 想要淺色或深色，用首頁副標右邊的切換鈕：沒按過就跟著系統，按過一次就記住你的選擇。
